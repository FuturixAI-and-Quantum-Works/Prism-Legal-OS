# Repository workflow

- Use `/poteto-mode` for every implementation phase.
- Run `/deslop` before every commit.
- Run `/no-comments` before every review.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (FuturixAI-and-Quantum-Works/Prism-Legal-OS) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
